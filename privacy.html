Inventory Sync App — Privacy Policy

Last updated: October 25, 2026

Operator and purpose

Inventory Sync App is a private seller tool operated by Ko-Box to connect the operator's eBay seller account and support product listing and inventory synchronization.

Information processed

The current version processes OAuth access and refresh tokens and retrieves the authorized seller's listing information, including item IDs, titles, prices, quantities and variations. It does not request buyer information, payment details or order data. The app does not receive or store the seller's eBay password.

Use and storage

Information is used for account connection, connection testing and inventory management development. OAuth tokens are encrypted before storage in Cloudflare D1. The application does not intentionally print token values in its logs.

Sharing

Information is not sold or used for advertising. eBay provides the connected API service, and Cloudflare provides application hosting and database infrastructure. This public policy page is hosted on GitHub Pages and contains no seller credentials or private account data.

Retention and deletion

Stored credentials are retained while needed for the connection or development testing. The operator can erase the stored credentials from the application database and remove retained listing exports when no longer needed. Access can also be revoked in the seller's eBay account settings. Revoking access does not itself erase previously stored data.

Contact

For privacy or deletion requests, contact Ko-Box through https://ko-box.vn/.

Updates

This policy will be updated when the application's data handling changes, including before adding buyer or order processing.
